# FunHouse Quiz

Простая викторина + таблица результатов конкурсов. Один процесс Node.js, без внешних сервисов.
База — локальный SQLite-файл `data.db`.

## Запуск

1. Установи Node.js 22+ (https://nodejs.org)
2. В папке проекта:
   ```
   npm install
   ```
3. Создай `.env` (или скопируй `.env.example`):
   ```
   PORT=3000
   ADMIN_PASSWORD=твой-пароль
   ```
4. Запуск:
   - Windows: двойной клик `run.bat` или `npm start`
   - Любой ОС: `npm start`

Открой http://localhost:3000/admin

## Страницы

- `/play` — игрок: вопрос, 4 варианта, таймер
- `/board` — табло результатов (для проектора/ТВ)
- `/admin` — админка (пароль из `.env`)

## Как играть

1. В админке создай игру → получишь PIN.
2. Добавь вопросы (или используй автосозданные при создании игры).
3. Игроки заходят на `/play`, вводят PIN и ник.
4. В админке «Управление» → подключись к PIN → Старт.
5. Таймер идёт на сервере; после истечения показывается правильный ответ.
6. «Следующий вопрос» переключает.
7. Ручные баллы за живые конкурсы — вкладка «Ручные баллы».

## Подключение с других устройств

- В одном Wi-Fi: `http://IP-компьютера:3000` (узнать IP: `ipconfig`).
- Из интернета: бесплатный туннель Cloudflare:
  ```
  cloudflared tunnel --url http://localhost:3000
  ```
  Даст публичную https-ссылку.

## Деплой на бесплатный хостинг (Render и т.п.)

Загрузи проект на GitHub, создай Web Service на Render (бесплатно).
Важно: бесплатный инстанс засыпает через 15 мин — перед игрой открой страницу, чтобы разбудить.
SQLite-файл на бесплатном Render не сохраняется между деплоями — для выходных ок, для постоянного использования лучше VPS.
